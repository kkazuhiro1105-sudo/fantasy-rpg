# 幻想世界 RPG ブラウザ版 v0.1

## この版でできること
- スマートフォン、iPad、パソコンのブラウザで表示できるレスポンシブ画面
- タイトル画面
- 主人公作成（性別・雰囲気、種族、獣人系統、職業、外見）
- 固定1D6 + 追加12D6の配分（各能力値の追加上限10D6）
- 6能力値のロール、振り直し（振り直し時は配分からやり直し）
- 主人公名入力、最終確認
- 作成した主人公をブラウザ内に一時保存し、JSONファイルとしてダウンロード

## 起動方法
### かんたんな確認
`index.html` をブラウザで開いてください。PCでは通常そのまま動きます。
スマートフォンやiPadでは、ZIPを展開してHTMLを直接開く操作が端末によって難しいため、下記の公開方法がおすすめです。

### URLで遊べるようにする
このフォルダ内のファイルを静的Webホスティング（例：GitHub Pages）にアップロードして公開します。
公開後は発行されたURLをSafari/Chromeで開くだけで遊べます。
GitHubアカウントの作成・リポジトリ作成・アップロード・Pages有効化が必要です。

## ファイル
- `index.html`: 画面構造
- `style.css`: デザインと端末別レイアウト
- `app.js`: キャラクター作成処理

## 注意
- これはPython/Pygame版の仕様を引き継ぐブラウザ移行の初期版です。Python版と全機能が同じになった完成版ではありません。
- 召喚・仲間管理・戦闘・冒険・安全地帯セーブはまだ実装していません。
- 保存はブラウザ内の `localStorage` に直近の主人公データを保存する簡易機能です。複数端末間の同期や正式なセーブデータ管理ではありません。
- 画面表示やコードの静的チェックは行っていますが、実機のSafari/Chromeでの動作確認はこれからです。
- Google Fontsを読み込む箇所があります。インターネット接続がない場合は端末標準フォントに切り替わります。
