幻想世界RPG ブラウザ版 v0.7

変更点
- キャラクター外見から装飾品・顔パーツの選択欄を削除
- 髪型選択を髪のシルエットだけのカード表示に変更
- 選んだ髪型と髪色を左側の主人公プレビューに重ねて反映
- 目の色・肌の色を個別に選択可能
- 雰囲気に加えて性格の選択を追加
- 種族は人間・エルフ・獣人の3種類

使い方
index.htmlをブラウザで開くか、GitHub Pagesへアップロードしてください。
assetsフォルダは必ずindex.htmlと同じ階層に置いてください。

注意
現在のキャラクター画像は種族ごとのベースイラストです。髪型はプレビュー上にシルエットを重ねて表現する試作実装です。専用の髪型別高品質イラストは今後差し替え可能です。
